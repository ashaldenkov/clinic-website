# 🏥 Patient Dashboard – Frontend Assignment

Cloud build - https://clinic-website-psi.vercel.app/

A responsive web dashboard for fetching and displaying patient data in a clear, visual way.  
Created as a frontend assignment for rendering dynamic medical information using **React**, **TailwindCSS**, and **Chart.js**.

---

## ✨ Description

This web app displays clinical data for a specific patient (Jessica Taylor) as required by the assignment. It fetches dynamic data from an external API (with basic authorization) and visualizes it using interactive charts and a structured UI. Focused on creating a **desktop-only** layout for medical staff usage on PCs.

---

## 🚀 Features

- 🧾 Patient overview: vital stats, test results, and visit info
- 📊 Beautiful data visualization with **Chart.js**
- 💅 Styled with **TailwindCSS** for clean and modern layout
- ⚡ Dynamic data fetching from remote API

---

## 🧰 Tech Stack

- **React** (with functional components)
- **JavaScript (ES6+)**
- **TailwindCSS**
- **Chart.js**
